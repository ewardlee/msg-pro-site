What Living Desktop does

A desktop you can actually use as a workspace.

The V1 product focuses on safe references, fast access, local organization and a quieter daily desktop—not taking ownership of Windows Explorer icons.

▦

Reference-based Fences

Group files, folders and shortcuts into persistent desktop Fences while leaving the originals in their existing Windows locations.

◇

Scenes

Switch between small work contexts such as Daily, Create and Play without duplicating source files.

▰

Quick Shelf

Keep frequently needed references ready without reorganizing the underlying folders.

◷

Today

See recent files only from folders you explicitly choose. No broad background crawl of your whole drive.

□

Folder Portals

Open a bounded view of a referenced folder directly on the desktop, with normal Explorer access still available.

✎

Post-its and local widgets

Keep small notes and useful local Windows information in the same workspace without a cloud account requirement.

Local-first by design

Organize without silently moving your originals.

Living Desktop 1.0 uses reference-based Fences. Adding, moving or unlinking a reference inside Living Desktop does not promise to move, copy or delete the original file or Windows desktop icon. Version 1.0 also contains no advertising, analytics or background upload of your files, paths, notes or usage history.

Questions

Before launch

Can I buy Living Desktop now?

No. The product is in final commercial release preparation. This page is informational and there is no active checkout or public retail installer yet.

Is it a Stardock Fences replacement?

Living Desktop V1 is a desktop organizer with its own reference-based Fences and related workflow tools. It does not claim to take over or physically reposition your existing Windows Explorer desktop icons.

Does it upload my files or notes?

Version 1.0 is local-first and does not implement product telemetry, advertising or a background upload service for file contents, paths, notes or system metrics.

Which Windows versions are supported?

Final retail system requirements will be published with the signed release. The public installer is not available while release signing and commercial onboarding are still in progress.
